# Ivory Premium

라이트 럭셔리. **아이보리 배경 + 딥 브라운 텍스트 + 골드 악센트**로 살롱의 고급감을 낸다.
다크(editorial-dark)의 라이트 짝이다.

## 색 = 신호 (반드시 지킴)
- **마젠타 `#ff3bff`** = 고통점에만 (라이트 위에서도 강한 신호로 작동).
- **골드 `#a07b2e`** = 약속점·CTA. (옐로 `#ffd400`은 아이보리 위에서 안 뜨므로 골드로 대체 — 신호의 "약속" 역할은 동일.)
- 본문은 딥 브라운 `#231d17` / 뮤트 `#a89a82`.

## 골격 (상단 → 중앙 → 하단)
상단 브랜드+배지 / 중앙 대형 헤드라인 / 하단 골드 CTA 바. editorial-dark와 동일 골격, 명암만 반전.

## 모션 노트
느린 fade/scale, 헤어라인이 그어지며 구획. 라이트라 그림자보다 얇은 선·여백으로 위계를 만든다.

## 언제 쓰나
밝고 우아한 톤이 맞는 캠페인. 럭셔리 살롱·프리미엄 포지셔닝. 다크가 무겁게 느껴질 때의 대안.

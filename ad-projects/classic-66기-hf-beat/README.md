# 클래식과정 66기 — 광고 영상 (비트 동기 재연출)

`ad-projects/classic-66기-hf`(34.5초 판)의 **연출만 갈아엎은** 판이다.
**메시지는 66기 확정본을 따르고**, 길이·컷 리듬·레이아웃·사운드를 새로 짰다.

- 규격: **9:16 · 1080×1920 · 30.2976초 · 30fps** (+ 4:5 · 1:1 파생)
- BGM: `born-fighter.mp3` (정본 `remotion/public/audio/`, 작업 사본 `audio/bgm.mp3`)

## 비트 그리드

`hyperframes beats` 검출값 — 첫 비트 `0.592s`, 간격 `0.3156s`(190BPM), 편차 0.001초.
음원을 **비트 #16 = 5.6416초**(마디 시작)부터 잘라 써서 **영상 t=0 이 정박**에 떨어진다.
컴포지션의 모든 시각은 예외 없이 `B = 0.3156`의 배수다.

```
1비트 = 0.3156s    1마디 = 8비트 = 2.5248s    전체 = 12마디 = 96비트 = 30.2976s
컷 26개 = 4비트컷 22개 + 2비트컷 4개 (빈틈·겹침 0)
```

### 전 구간 상시

- **컷 8개가 전부 정박에서 끊긴다** — 컷마다 화면이 1.055배에서 눌려 펴진다
- **마디마다(12회) 화면 전체가 한 번 펌프**
- **어절 단위 등장** — 카피를 어절로 쪼개 비트마다 하나씩. 강조어 6개는 슬램(1.26~1.50배에서 착지)
- 하단 비트 마커가 마디마다 한 칸씩 (12칸)

## 레이아웃 — 안전영역

`_brand/frame.md` 의 `safe_area_y: [330, 1580]`. 4:5 중앙크롭 창(y 285~1635)보다 45px 안쪽이다.

**실측 결과 전 구간 y 330~1571** — 4:5 파생 시 무손실.
65기에서 워터마크(`bottom:96px` = y≈1824)가 4:5에서 잘린 결함이 있었다. 이 판은 워터마크 `top:1512`,
비트바 `top:1566`, CTA 바 `top:630`(블록 기준)으로 전부 안쪽에 뒀다.

## 대비

실사가 밝다(흰 벽·흰 가운). 영상을 어둡게 눌러 대비를 맞추면 화면이 탁해지므로,
**밝기는 0.92 로 유지하고 글자에 `-webkit-text-stroke: 1.5px` 를 줘서** 해결했다.
hyperframes 대비 감사기는 stroke 를 글리프 페인트로 인정해 fill/stroke 중 높은 쪽을 채택한다.

## 소재 — 같은 영상이 두 번 나오지 않는다

**원본 촬영본은 6개뿐이다.** 한 촬영본을 시간만 달리해 여러 번 자르면 파일은 달라도
화면에는 "같은 장면이 또 나온다"로 읽힌다. 실제로 그렇게 만들었다가 광고주가 지적했다.

그래서 4K 세로 원본(2160×3840)을 **화각까지 다르게 크롭**해 샷을 만든다.
1080 출력이라 2배까지는 화질 손실이 없다.

```
WIDE  = 전체 화각          MID = crop 1512x2688 (1.43배)      TIGHT = crop 1296x2304 (1.67배)
```

`make-clips.sh` 가 만드는 **8개 샷을 영상에서 딱 한 번씩만** 쓴다. 실사 17.0초 / 다크 13.3초.

## 비율 3종

| 비율 | 만드는 법 | 파일 |
|---|---|---|
| **9:16** | `index.html` 렌더 (원본) | `classic-66기-beat-reels-v01.mp4` |
| **4:5** | `./make-feed-sizes.sh` — 중앙 크롭 `crop=1080:1350:0:285` | `classic-66기-beat-4x5-v01.mp4` |
| **1:1** | `./make-1x1.sh` → `index-1x1.html` 별도 렌더 | `classic-66기-beat-1x1-v01.mp4` |

**1:1 은 중앙 크롭 금지** — 상단 배지·하단 CTA 가 잘린다(`docs/video-hyperframe.md` §5).
`make-1x1.sh` 가 `index.html` 의 `<style>` 자리에 `styles/square.css` 를 끼워 넣어 생성한다.
**씬 구성·타임라인·카피는 두 파일이 완전히 동일하다** — 카피나 연출을 바꾸면 `index.html` 만
고치고 `./make-1x1.sh` 를 다시 돌린다.

`index-1x1.html` 을 `compositions/` 아래 두지 않는 이유: 린트가 자산 경로를 `compositions/`
기준으로 재작성해 `video/`·`fonts/` 를 못 찾고 `missing_local_asset` 에러를 낸다. 루트에 둔다.

## 명령

```bash
cd ad-projects/classic-66기-hf-beat
npm run check     # lint + 런타임 + 레이아웃 + 모션 + 대비
npm run beats     # 비트 그리드 재검출 → beats/audio/bgm.mp3.json
npm run render    # MP4
```

> ⚠️ 이 WSL 은 커널이 자동 배정한 포트에 즉시 접속이 안 돼 렌더가 죽는다. 앞에 shim 을 붙인다.
> ```bash
> gcc -shared -fPIC -O2 -o /tmp/bindfix.so ../../scripts/wsl-bindfix.c -ldl
> LD_PRELOAD=/tmp/bindfix.so npm run render
> ```

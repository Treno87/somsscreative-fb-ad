# 클래식과정 66기 — 광고 영상 (비트 동기 재연출)

`ad-projects/classic-66기-hf`(34.5초 판)의 **연출만 갈아엎은** 판이다.
**카피·메시지는 66기 확정본 그대로**이고, 길이·컷 리듬·레이아웃·사운드를 새로 짰다.

- 규격: **9:16 · 1080×1920 · 25.25초 · 30fps**
- BGM: `born-fighter.mp3` (정본 `remotion/public/audio/`, 작업 사본 `audio/bgm.mp3`)

## 왜 다시 만들었나

34.5초 판이 밋밋했던 원인은 모션이 아니라 구조였다.

| 길이 / 컷 | 34.5초 / 6컷 (씬당 5.75초) | **25.25초 / 22컷 (평균 1.15초)** |

| 실사 배치 | 920×920 정사각 상자 고정 | **1080×1920 풀블리드** |
| 실사 화질 | 720p·608px 로 축소 | **세로 4K 원본에서 1080×1920** |
| 쓴 원본 | 3개 | **6개 전부** (`IMG_9299` 강의실 현장 신규 투입) |

## 비트 그리드

`hyperframes beats` 검출값 — 첫 비트 `0.592s`, 간격 `0.3156s`(190BPM), 편차 0.001초.

음원을 **비트 #16 = 5.6416초**(마디 시작)부터 잘라 써서 **영상 t=0 이 정박**에 떨어진다.
컴포지션의 모든 시각은 예외 없이 `B = 0.3156`의 배수다.

```
1비트 = 0.3156s      1마디 = 8비트 = 2.5248s      전체 = 10마디 = 25.248s
```

## 명령

```bash
cd ad-projects/classic-66기-hf-beat
npm run check     # lint + 런타임 + 레이아웃 + 모션 + 대비
npm run beats     # 비트 그리드 재검출 → beats/audio/bgm.mp3.json
npm run render    # MP4
```

> ⚠️ 이 WSL 에서는 렌더 앞에 `LD_PRELOAD` 가 필요하다. 자세한 건 `scripts/wsl-bindfix.c` 참고.
> ```bash
> gcc -shared -fPIC -O2 -o /tmp/bindfix.so ../../scripts/wsl-bindfix.c -ldl
> LD_PRELOAD=/tmp/bindfix.so npm run render
> ```
